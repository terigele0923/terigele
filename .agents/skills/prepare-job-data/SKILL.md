# 就活データの準備

1. プロジェクトルートの `.agents/rules/job-data.md` と `~/.codex/data/job_data.template.json` を読む。ひな型を参照できなければ、項目を推測せずに報告する。
2. 指定された元資料と回答を照合し、学歴・職歴・資格・実績を対応する項目へ整理する。応募先別の依頼では、企業名と職種を確認し、求人要件や志望動機を対応する項目に整理する。
3. 食い違いや不足のうち、対象書類に必要な事項をまとめて本人に確認する。回答待ちの項目は空欄にし、確認事項を `information_to_confirm` にまとめる。
4. 接頭語で許可された作業範囲に従う。検討やヒアリングではチャット上で案を示す。JSON の保存を依頼されたら、既存の入力を上書きしないよう出力先を確認してから保存する。
5. 保存した JSON は、対象書類を指定して `.agents/scripts/Generate-JobDocuments.ps1` を `-ValidateOnly` 付きで実行する。基本チェックの結果と残った確認事項を伝える。書類生成は依頼された場合に実行する。
