# 就活データと書類生成

- 元資料は `docs/documents/` に置く。入力 JSON の項目は `~/.codex/data/job_data.template.json` に合わせる。
- 学歴・職歴・資格・実績は本人の回答または元資料に基づいて記録する。食い違いは、どの情報が異なるか示して確認する。未確認事項は `information_to_confirm` に記録する。
- 共通の本人情報を再利用し、求人ごとの志望動機や面接メモは応募先ごとの入力 JSON に持たせる。求人側の要件と本人の経験を区別する。
- 個人情報を含む元資料・入力 JSON・生成書類は、本人の明示的な指示がある場合に限り共有やコミットの対象にする。
- 生成の入口は `.agents/scripts/Generate-JobDocuments.ps1`。既定の出力先は `docs/deliverables/`。ツールを検証するときは、空のひな型や架空の検証用データを使う。
